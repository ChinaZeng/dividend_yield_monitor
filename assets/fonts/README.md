# Bundled report font

`NotoSansCJKsc-Regular.otf` is the Simplified Chinese regular face from
[Noto CJK](https://github.com/notofonts/noto-cjk).

- Source path: `Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf`
- SHA-256: `2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`
- License: SIL Open Font License 1.1; see `OFL.txt` in this directory.

The complete font is bundled instead of a glyph subset so newly configured
Chinese stock names render correctly without rebuilding the asset.
